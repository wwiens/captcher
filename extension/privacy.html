Privacy and capture limits

Captcher Recorder is free software published by Noventix LLC, which receives nothing from it. You choose what to record and when to submit it. Use synthetic data, and review the resulting draft before sharing.

What is recorded

Starting a recording saves HTML snapshots and interactions from the starting tab and tabs opened from that flow. Snapshots can contain visible and hidden page content, ordinary form values, URLs, titles, images, styles and fonts. Each captured page also includes a viewport screenshot. Single-page capture saves the page you select. Recording stops on Finish, Discard, panel closure or loss of its connection.

Outside a recording, the panel inspects active-tab URLs to support pairing and contacts only the Captcher server set in its settings. A presence script announces the installed extension on that server. It does not run a general browsing-history or analytics collection service.

What redaction can and cannot do

Recognized password fields (including ones revealed with a show-password button), password/one-time-code/card autocomplete controls, fields named like passwords, PINs or card codes, and hidden inputs are blanked during capture. This includes sensitive dropdowns, templates, open and closed shadow roots, and accessible same-origin frames. Form values are restored afterwards. Sensitive actions use placeholders. Screenshots are taken after these fields are blanked, so they show them empty (password fields show only their masking dots). Content inside embedded frames from other sites cannot be blanked and appears in screenshots as displayed.

Capture stops if protection cannot be verified, including inaccessible or loading frames and embedded objects. Common encoded reflections are checked; ambiguous short values can cause capture to stop. Redaction does not identify every secret in ordinary text, URLs, images, canvases, custom encodings or unmarked fields. Personal, authentication, financial, health, location or communications data may therefore be included if it appears in what you record.

Where data goes

Submit sends the capture, with the panel's activity log for that capture (the same lines the panel shows, used for troubleshooting), to the connected Captcher server shown in the panel. Captcher is self-hosted: the extension pairs with and sends to only the one server address set in its settings, which defaults to Captcher on this computer (http://127.0.0.1:8080). A server on another machine must use HTTPS. Nothing is sent to the Captcher project or anyone else. Whoever runs that server decides what happens to recordings; Captcher itself sends page content to Anthropic when its AI features author or edit a walkthrough, using that server's own API key. The extension contains no advertising or analytics SDK.

To embed page resources, the capture engine requests URLs named by the page using the page's browser-enforced access rules. Its fetch adapter omits credentials, rejects redirects and limits each response to 32 MB. There is no privileged cross-origin resource proxy. Resource servers can receive ordinary connection metadata, including your IP address and requested URL. Missing or blocked resources can reduce snapshot fidelity.

Local storage and control

When it pairs, the extension sends the Captcher server a device label (browser name, operating system and recorder version) so you can recognize the connection on its Settings page. The extension stores the server address, device token and preferences in local extension storage. Content scripts cannot read that storage. Captures and logs stay in panel memory until submission, download or closure. Closing the panel loses unsent work. Downloads remain wherever you save them; uninstalling the extension does not delete downloads or recordings already submitted to the service.

Use Reconnect in Settings to replace the connection, or change the server address to connect somewhere else. Revoking the device on the server's Settings page prevents future uploads from this browser. If an upload is rejected, reconnect and retry while keeping the panel open. Removing the extension clears its extension storage.

Questions and data requests

Recordings live on the Captcher server they were sent to, so requests about them go to whoever runs that server. Captcher is open source; questions about the extension itself go to the project's issue tracker.
