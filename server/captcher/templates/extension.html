The recorder

Chrome extension

Record a task in your browser and send the captured screens to Captcher. Load the extension into Chrome, then connect it to this Captcher.

01 · Install 02 · Connect Troubleshooting

Step 01 / Install

Load the extension into Chrome

Captcher Recorder comes with Captcher, as a folder you load into Chrome. __EXTENSION_DIR__

  1. In Google Chrome, open chrome://extensions.
  2. Turn on Developer mode (top right).
  3. Click Load unpacked and choose that folder. It sits inside a hidden folder: on a Mac, press Cmd+Shift+G in the dialog and paste the path; on Windows or Linux, paste it into the dialog's address bar.
  4. Click Chrome's Extensions menu (the puzzle-piece icon beside the address bar), then click the pin beside Captcher Recorder to keep it on your toolbar.

Chrome does not update an unpacked extension by itself: after updating Captcher, click the reload arrow on the extension's card in chrome://extensions.

Step 02 / Connect

Connect this browser to Captcher

  1. Return to this Captcher page in the same Chrome profile where you loaded the extension.
  2. Refresh this page after installing, then click the Captcher Recorder icon in Chrome's toolbar to open its side panel. Keep this tab active.
  3. The panel opens Set up the recorder and connects automatically to this page. If you see Connect this browser, click it to open setup. If Captcher is not at http://127.0.0.1:8080, enter its address under Captcher server and press Save.
  4. Wait for Connected and check the server shown in the panel. The panel then opens the recording controls.

You do not need to paste an address, token or API key. Each connected browser receives its own key.

You can review or revoke connected browsers on the Settings page.

Before you start

What you need

Google Chrome on a desktop or laptop, Captcher running, and permission to load extensions in your Chrome profile.

If your organization manages Chrome and restricts which extensions can be installed, ask your administrator to allow Captcher Recorder.

After connecting

Record your first walkthrough

Open the web application you want to teach. Keep the recorder's side panel open, enter a walkthrough title, and click Start recording.

Perform the task, then click Finish & submit. Wait for the upload to finish, then open Walkthroughs to find your capture and author it with AI.

Follow Getting started for the full recording-to-sharing tutorial.

Troubleshooting

Load unpacked is missing or blocked

Turn on Developer mode in chrome://extensions first. If your organization manages Chrome, it may block unpacked extensions; ask your administrator.

The extension icon is missing

Open chrome://extensions and check that Captcher Recorder is enabled. Open the Extensions menu beside the address bar and pin Captcher Recorder. Check that you are using the Chrome profile where you installed it.

The recorder does not connect

Keep a Captcher page active in the same Chrome profile as the extension, and check that the address under Captcher server in the panel is the one in your address bar. Refresh the page, reopen the side panel, and press Try again if it appears. Chrome's Extensions page cannot complete the connection.

I need to update the extension

If the side panel says a newer version is required, finish and submit any recording first, then click the reload arrow on Captcher Recorder in chrome://extensions. Refresh your Captcher tab and reopen the side panel.

If setup appears again, follow the connection steps above.
